# KrazyCare Drug Store

## Website Project

KrazyCare Drug Store is a fictional luxury pharmacy website developed for the WEDE5020 Web Development (Introduction) 2026 POE.

The website presents a professional healthcare and pharmacy brand called KrazyCare Drug Store, using the tagline:

**"Luxury Healthcare, Redefined."**

The website focuses on providing users with information about pharmacy products, healthcare services, company information, news, enquiries and contact details.

---

## Website Pages

The website contains the following pages:

- `index.html` - Home page
- `about.html` - About KrazyCare Drug Store
- `products.html` - Products and healthcare services
- `gallery.html` - Pharmacy image gallery
- `news.html` - News and healthcare updates
- `enquiry.html` - Product and service enquiry form
- `contact.html` - Contact information and contact form

---

## Main Features

### Responsive Navigation

The website includes a navigation menu that allows users to move between all seven pages.

The navigation is designed to remain usable across desktop, tablet and mobile screen sizes.

### Responsive Design

The website uses CSS media queries, flexible layouts and relative sizing to support different screen sizes.

The website was tested at:

- Desktop
- Tablet
- Mobile

### Products and Services

The Products & Services page presents the main product categories and healthcare services offered by the fictional pharmacy.

Products include:

- Prescription Medicines
- Over-the-Counter Medicines
- Vitamins & Supplements
- Luxury Skincare Products
- Baby Care Products
- Medical Equipment

Services include:

- Prescription Refills
- Health Consultations
- Vaccinations
- Blood Pressure Monitoring
- Medication Delivery
- Health Screening

### Product and Service Search

The Products & Services page includes a JavaScript search feature.

Users can enter a keyword to filter the displayed products and services.

The search provides feedback when:

- Matching items are found
- No matching items are found
- The search field is empty

### Enquiry Form

The Enquiry page allows users to submit enquiries about:

- Product availability
- Healthcare services
- Prescription support
- Luxury skincare
- Wellness and supplements

JavaScript is used to process the enquiry and display a response based on the selected enquiry type.

### Gallery Lightbox

The Gallery page includes an interactive JavaScript lightbox.

Users can:

- Click an image to enlarge it
- Close the enlarged image using the close button
- Click outside the enlarged image to close it
- Press the Escape key to close the lightbox

The lightbox is responsive for smaller screens.

### FAQ Accordion

The About page includes an interactive FAQ accordion.

Users can click a question to display or hide its answer.

This feature uses JavaScript DOM manipulation.

### Interactive Map

The Contact page includes an interactive map using Leaflet and OpenStreetMap.

The map includes a marker representing the fictional KrazyCare Drug Store location in Johannesburg, South Africa.
